# @handovernow/cms-cloudflare

## 0.0.1

Initial HandoverNow EmDash CMS Cloudflare deployment package.

This package was copied from the upstream Cloudflare demo and reduced to a free-plan-safe vanilla CMS deployment using:

- Astro server rendering
- EmDash CMS
- Cloudflare Worker
- D1 database binding
- R2 media bucket binding
- Cloudflare cache provider

The copied isolated third-party extension demo was intentionally removed from runtime configuration for this milestone.
